
# Simple Quiz App

An interactive multiple-choice quiz application built with HTML, CSS, and JavaScript. The app displays questions, checks answers, tracks the user's score, and allows the quiz to be restarted.

## Features

* Multiple-choice questions
* Instant answer feedback
* Score tracking
* Restart Quiz functionality
* Interactive user interface
* Responsive and simple design

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Purpose

This project was created to practice JavaScript concepts including arrays of objects, functions, conditional statements, event handling, DOM manipulation, and basic application logic.

## Future Improvements

* Add a timer
* Add a question counter
* Add more quiz categories
* Add difficulty levels
* Add a final score summary
